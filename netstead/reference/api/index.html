    netstead API reference ¶

    GMNS-specific surface. For the generic Frictionless data-package primitives (Package, Table, validation, editing framework, HTTP + MCP factories) see the corral API reference.

    Auto-generated from package docstrings via mkdocstrings. Stable anchors match the codes in ai/api-index.json. This page covers the core surface — Network, spec, semantics, scope, quality, indexes, graph, clean — plus the builders, selection, map, settings and Workbench entry points; smaller helpers are documented in their modules’ docstrings.

    Network — the GMNS-aware Package ¶

    netstead.Network(spec_version=None) dataclass ¶

    Bases: Package

    GMNS-aware :class:~corral.dataset.Package.

    Subclass of :class:~corral.dataset.Package that defaults to the bundled GMNS spec (see :mod:netstead.spec) and exposes named accessors for the canonical GMNS resources (link, node, segment, lane, geometry, link_tod, signal_controller, …). Validation reports produced by :meth:validate carry the active :attr:spec_version so saved JSON / HTML reports are self-describing.

    Attributes:

    Name Type Description
    spec_version str | None

    GMNS spec version this network was loaded against — one of :data:netstead.spec.SUPPORTED_SPECS. Populated by :meth:from_source; defaults to "" when the dataclass is constructed directly (the structural check still works, but :meth:validate’s stamp will be empty until the caller sets it).

    Examples:

    Load the bundled Leavenworth fixture, hit the named accessors, and run validation::

    >>> from netstead import Network
>>> from netstead.fixtures import leavenworth
>>> from corral.engines.ibis_engine import IbisEngine
>>> net = Network.from_source(leavenworth.csv_dir(), engine=IbisEngine())
>>> net.links.name
'link'
>>> net.nodes.name
'node'
>>> net.segments is None  # Leavenworth has no segment table
True
>>> report = net.validate()
>>> report.spec_version == net.spec_version
True

    netstead.NetworkError ¶

    Bases: PackageError

    A GMNS-required resource is missing or violates GMNS semantics.

    Specialises :class:~corral.dataset.PackageError so generic package-error handlers still catch it, while GMNS-aware callers can branch on the more specific type. Raised today by :attr:Network.links / :attr:Network.nodes when the underlying resource is absent from the loaded package; task 3.8 will reuse it for GMNS-semantics violations (broken connectivity, missing TOD references, …).

    Semantics ¶

    netstead.semantics.is_connected(net) ¶

    Return True iff the network has exactly one weakly-connected component.

    “Weakly connected” means we ignore link direction — a one-way pair of streets between two nodes counts as connected.

    Examples:

    >>> from netstead import Network
>>> from netstead.fixtures import leavenworth
>>> from corral.engines.ibis_engine import IbisEngine
>>> net = Network.from_source(leavenworth.csv_dir(), engine=IbisEngine())
>>> is_connected(net)
True

    netstead.semantics.connected_components(net) ¶

    Return the network’s weakly-connected components, largest first.

    Each component is a set of node_ids. Sorted by len descending so connected_components(net)[0] is always the largest. Empty networks return [].

    Examples:

    >>> from netstead import Network
>>> from netstead.fixtures import leavenworth
>>> from corral.engines.ibis_engine import IbisEngine
>>> net = Network.from_source(leavenworth.csv_dir(), engine=IbisEngine())
>>> comps = connected_components(net)
>>> len(comps) >= 1
True
>>> all(len(comps[i]) >= len(comps[i + 1]) for i in range(len(comps) - 1))
True

    netstead.semantics.assemble_link_geometry(net) ¶

    Return (link_id, geometry, source) for every link in net.

    geometry is WKB bytes (the canonical in-memory encoding; geometry ADR) or null. Resolution order per link row:

    1. Inline link.geometry (non-null) — source = "inline".
    2. link.geometry_id resolving in net.geometry — source = "geometry_table".
    3. Straight segment from from_node_id / to_node_id node coords, encoded as a WKB LINESTRING — source = "node_endpoints".
    4. None of the above (geometry column absent + geometry_id absent + endpoint nodes missing coords) — geometry = None, source = "missing".

    Inline/table cells are pass-through when already WKB; a legacy WKT string is re-encoded, so the function is correct whether or not the network’s geometry was canonicalised on load.

    Scope ¶

    netstead.scope.NetworkScope(node_ids, link_ids, network, provenance='') dataclass ¶

    An immutable subset of a :class:Network’s links + nodes.

    Built by the module-level constructors (:func:from_nodes, :func:from_node, :func:from_link, :func:from_point, :func:connected_component, :func:from_zone) and composed via :meth:union / :meth:intersect / :meth:subtract / :meth:buffer_network / :meth:buffer_spatial. :meth:apply materialises the scope as a fresh :class:Network with all FK-related tables pre-filtered.

    Attributes:

    Name Type Description
    node_ids frozenset[int]

    frozenset of node ids in the scope.
    link_ids frozenset[int]

    frozenset of link ids in the scope.
    network Network

    the source :class:Network (used by composition ops to access the cached indexes; not re-validated on the return path of :meth:apply).
    provenance str

    short human-readable trail of how this scope was built (e.g. "from_nodes([1,2,3], path_between=True)"). Used in error messages and scope.repr.

    Examples:

    >>> import pytest
>>> _ = pytest.importorskip("scipy")
>>> from netstead import Network
>>> from netstead.fixtures import leavenworth
>>> from corral.engines.ibis_engine import IbisEngine
>>> from netstead.scope import from_nodes
>>> net = Network.from_source(leavenworth.csv_dir(), engine=IbisEngine())
>>> scope = from_nodes(net, [1, 2], path_between=True)
>>> isinstance(scope, NetworkScope)
True
>>> sub = scope.apply()
>>> sub.links.count() <= net.links.count()
True

    apply() ¶

    Return a new :class:Network whose tables are filtered to the scope.

    Pushdown rules:

    • link -> rows where link_id is in :attr:link_ids.
    • node -> rows where node_id is in :attr:node_ids.
    • geometry -> rows whose geometry_id is referenced by any surviving link.
    • Other tables in :data:_FK_PUSHDOWN -> rows where any of their FK columns match the scope’s id sets.
    • Tables outside :data:_FK_PUSHDOWN (e.g. time_set_definitions, use_definition) pass through unfiltered — they are dimension tables, not network-keyed.

    union(other) ¶

    Return the union of two scopes (same network).

    intersect(other) ¶

    Return the intersection of two scopes (same network).

    subtract(other) ¶

    Return the set-difference (self minus other) of two scopes (same network).

    buffer_network(distance) ¶

    Extend the scope by all nodes within distance network-distance of any current node.

    Adds the induced links (any link whose endpoints are both in the expanded node set) so the result remains a proper subgraph.

    buffer_spatial(distance_m) ¶

    Extend the scope by all links within distance_m of any current link’s geometry.

    Implementation note: builds a shapely union of the current scope’s link geometries, then queries the SpatialIndex with distance_m as a buffer. Endpoint nodes of any newly added links are folded in too.

    Quality (GMNS rule pack) ¶

    netstead.quality.register_all() ¶

    Construct + register every rule in this module.

    Wired as the corral.quality.rules entry point for the netstead distribution (see packages/netstead/pyproject.toml). Also callable directly from tests / ad-hoc scripts: register_all() returns the list of registered rule instances.

    The rule classes:

    netstead.quality.HighSpeedResidentialRule ¶

    Flag residential links with implausibly high free_speed.

    Threshold keys:

    • speed_limit_mph (default 35) — anything above is flagged.

    Looks at link.facility_type (matched against residential / local case-insensitively, ignoring surrounding whitespace) and link.free_speed. Skips links with null facility type or null free_speed (those belong to the MissingCriticalFieldsRule).

    The free_speed unit is whatever the spec’s long_distance_units field declares — GMNS defaults to mph, so the threshold key is named speed_limit_mph for clarity. If your network uses km/h, set speed_limit_mph to your km/h threshold; the comparison is unit-agnostic from the rule’s point of view.

    applies_to(package) ¶

    We need both the link table AND its facility_type + free_speed columns.

    run(package, report, rc=None) ¶

    Filter the link table in the engine; emit one issue per offending row.

    netstead.quality.DisconnectedComponentsRule ¶

    Flag networks with more than one weakly-connected component.

    Threshold keys: none (the presence of any extra component is the quality concern).

    Emits a single Severity.INFO issue (not per-component) listing the component count + sizes. connected_components is delegated to :mod:netstead.semantics.connectivity so the same GMNSGraph (scipy) build is shared with any other connectivity caller in the session. No table is materialised here: the graph index reads only the columns it needs.

    applies_to(package) ¶

    We need link + node tables AND the columns GMNSGraph.build needs.

    Skips silently on non-Network packages (no GMNS accessors) and on networks missing length on the link table — the upstream :class:~netstead.graph.GMNSGraph (built with cost="length") needs it and we’d rather no-op than blow up.

    run(package, report, rc=None) ¶

    Build (or reuse) the GMNSGraph, count components.

    netstead.quality.LaneCountMismatchRule ¶

    Flag links where link.lanes disagrees with the lane table row count.

    Threshold keys: none — any non-zero mismatch is flagged.

    Skips links where either link.lanes is null OR the lane table has zero rows for that link (those cases are “underspecified”, not “wrong” — caught by :class:MissingCriticalFieldsRule). A fractional link.lanes is compared by its whole part.

    applies_to(package) ¶

    Needs both the link table AND a lane table.

    run(package, report, rc=None) ¶

    Count lane rows per link in the engine, join to link.lanes, emit the mismatches.

    netstead.quality.DuplicateNearNodesRule ¶

    Flag pairs of nodes within epsilon_units of each other.

    Threshold keys:

    • epsilon_units (default 1e-5) — distance threshold in the node coordinate CRS units. The default is deliberately tiny so it means “effectively duplicate” in any CRS: ~1m for WGS84 at mid-latitudes; a hair’s breadth for projected coords. Tune it for your CRS. For projected networks (UTM, state plane) where coordinates are meters, 5.0 is a reasonable “near-duplicate” threshold. For WGS84 degrees, 0.0001 is roughly 10m. 0 flags only exact duplicates; a negative value raises :class:ValueError.

    Implementation: a grid self-join in the engine. Each node is hashed to an epsilon-sized grid cell and joined against the nodes of the 3x3 block of cells around it, so the work grows with the number of nodes, not its square; only the pairs within epsilon reach Python.

    applies_to(package) ¶

    Needs a node table with node_id + x_coord + y_coord columns.

    netstead.quality.NonUniqueCombinationRule ¶

    Flag rows that repeat a combination of columns that should be unique.

    GMNS 0.97 gives the time-of-day tables a surrogate primary key (link_tod_id, …), so two link_tod rows for the same link_id and time_day pass spec validation although they contradict each other. This rule groups each table by its natural key in the engine and reports every combination that occurs more than once.

    Threshold keys:

    • combinations (default :data:DEFAULT_UNIQUE_COMBINATIONS) — a mapping of table name to a list of column combinations, each a list of column names. Setting it replaces the defaults, so include every combination you still want checked. A default combination whose table or columns are absent is skipped silently; a configured one is logged (a WARNING on the netstead.quality.rules logger), since it is probably a typo. It is not an issue, so severity_override never escalates it. A value that isn’t a mapping of table name to a list of column lists raises :class:ValueError (settings reject it when they load).

    Rows with a null in any of the combination’s columns are skipped (a missing value is the schema validator’s concern, not a duplicate). Emits one issue per repeated combination: row is its first row, and extra carries columns, values (column → value), rows (the first 20 row positions) and count. Exact matches only: two time_day windows that overlap without being equal are not flagged.

    (The code and threshold avoid the word “key”: the Workbench refuses setting names ending in key, which it reserves for credentials.)

    applies_to(package) ¶

    Any package with tables: run resolves the configured combinations against what is present.

    run(package, report, rc=None) ¶

    Group each configured table by each key combination; emit one issue per repeated combination.

    netstead.quality.OverlappingLinksRule ¶

    Flag pairs of links whose shapes run along each other for part of their length.

    Threshold keys:

    • min_overlap_units (default 0.0) — a pair is flagged when the length they share is greater than this, in the geometry’s CRS units (degrees for WGS84; raise it to ignore digitising noise).

    A shared stretch is a 1-D intersection: links that only touch at a node or cross each other are not flagged. Pairs with identical shapes are skipped too, since that is how GMNS encodes the two directions of a two-way street; a link lying along part of a longer one is flagged. Emits one issue per pair, on the first link’s row, with extra link_ids, rows and overlap_length.

    Exact matching only. The test is GEOS’s exact DE-9IM relation with no snapping tolerance: only segments the two shapes share exactly are caught. Two digitisations of the same road a centimetre apart, or with vertices that don’t line up on a common segment, are not flagged. min_overlap_units filters short exact overlaps; it does not widen the match.

    Shapes come from inline link.geometry when set, else from the geometry table through link.geometry_id (the first row of a repeated geometry_id); links with neither are skipped. Requires shapely (clean extra). The engine selects just the link ids and shapes; candidate pairs come from an STRtree bounding-box query, are cut down in numpy, and only the survivors get the exact DE-9IM test (about 0.2 s on a 100k-link grid). The cost grows with how many bounding boxes overlap with real area, so it can get slow on long or diagonal links whose boxes cover much of the network (long rural links in WGS84, say).

    applies_to(package) ¶

    Needs shapely and a link shape source: inline geometry or geometry_id + a geometry table.

    run(package, report, rc=None) ¶

    Index link shapes in an STRtree; emit one issue per pair sharing more than min_overlap_units.

    The repair budget and temperature come from llm.quality. Raises :class:~netstead.llm.errors.MissingKey when a remote provider has no key.

    netstead.workbench.actions.BaseAction ¶

    Bases: BaseModel

    Base class for every Workbench Action, core and plugin.

    A subclass declares type: Literal["<type>"] = "<type>" (plugins: "<plugin id>.<name>") and its fields. mutates marks actions the assistant must draft before applying; runs_as_job (core only) runs the slow work on a background job thread; replay_overrides are fields forced in the to_python replay snippet, and replay_omits are fields it leaves out (a guard that only means something in the live session, such as a planned version). assistant = False keeps an Action out of the natural-language assistant’s tools, even when its plugin is opted in (Host API 1.4). assistant_compact = True offers a mutates Action in the assistant’s compact tool set too (assistant.compact_tools, on for a model on this machine): that set keeps the read-only Actions and only the mutating ones so marked (Host API 1.6).

    Field values must round-trip through repr (str, numbers, bools, None, lists/dicts/tuples of those, nested pydantic models): “copy session as Python” writes each field as name=<repr(value)>, so a value whose repr isn’t valid Python makes the copied script fail.
