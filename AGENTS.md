# Notes for AI agents working on netstead

Read before changing code or docs:

- **Workbench or plugin UI:** follow [docs/design/workbench-ui-style.md](docs/design/workbench-ui-style.md). It
  records the maintainer's standing UI decisions (icon buttons with tooltips, info-icon help, details in the right
  drawer, state words). Add new UI corrections there in the same PR.
- **Design in flight:** [docs/design/README.md](docs/design/README.md) lists accepted designs and their phases.
- **Spelling:** American English in UI text, docs, comments and commit messages. Never rename an identifier only
  for spelling.
- **Contributing, tests and docs builds:** [CONTRIBUTING.md](CONTRIBUTING.md).
