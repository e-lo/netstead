# Migrating from GMNSpy v0.3.x to Netstead v1.0

Netstead v1.0 is the successor to GMNSpy — a ground-up rewrite published
under a new name. The package name, public API, package layout, and
runtime engine all changed. This guide walks GMNSpy v0.3.5 users through
the breaking changes and shows the new equivalents.

If you need the old behavior, keep depending on `gmnspy<1` — v0.3.5 is the
last release of the old line and is no longer maintained. (An early
`gmnspy==1.0.0b1` preview of the rewrite was published under the old name
before the rename; it has been yanked and is superseded by `netstead`.)

## TL;DR

- v1.0 is a clean rewrite — **no automatic upgrade path, no compat shim,
  no `DeprecationWarning` bridges**. You will edit your imports.
- The codebase is split into two packages: **`corral`** (generic
  schema / validation / IO engine) and **`netstead`** (GMNS-specific
  bindings on top).
- Old: `import gmnspy; gmnspy.read_gmns_network(path)` →
  New: `from netstead import Network; Network.from_source(path)`.
- Validation returns a single `ValidationReport` — multiple renderers
  (rich terminal / JSON / HTML) replace ad-hoc `_check_*` helpers.
- Memory + performance are first-class: tables are **lazy DuckDB
  expressions** (driven through ibis). pandas / polars / Arrow are
  input and output formats, not engines — call `.to_pandas()` /
  `.to_polars()` only when you actually need the materialized frame.
- New **CLI**: `netstead validate`, `netstead info`, `netstead quality`, and
  the inherited `corral` commands. Every data command supports `--json`
  for AI / scripting consumption.

## Installation

**GMNSpy v0.3.x**

```bash
pip install gmnspy
```

**Netstead v1.0**

```bash
pip install netstead
```

`netstead` depends on `corral` (PyPI `dbcorral`), which is installed transitively.

## API mapping

| GMNSpy v0.3 (removed) | Netstead v1.0 (use this) | Notes |
|---|---|---|
| `import gmnspy` | `from netstead import Network` | Top-level helpers are gone — the entry point is the `Network` class. |
| `gmnspy.read_gmns_network(path)` | `netstead.Network.from_source(path)` | Returns a `Network` (subclass of `corral.Package`) with lazy tables, not a `dict[str, DataFrame]`. |
| `gmnspy.read_gmns_csv(path, validate=True)` | `corral.read(path)` for any table; or `Network.from_source(dir).<table>` | Format inference (csv / parquet / duckdb / zip-csv / URL) is automatic. |
| `gmnspy.validation.apply_schema_to_df(df, schema_file=...)` | `net.validate()` | Schema, foreign-key, structural, and sync-state checks all run from one call. |
| `gmnspy.validation.validate_foreign_keys(...)` | `net.validate()` then keep the issues whose `category` is `corral.validation.Category.FOREIGN_KEY` (or use `report.by_category()`) | Composite + self-referential FKs supported. |
| `gmnspy.validation._check_*` helpers | `report = net.validate(); report.issues` / `report.by_severity()` | The Series-vs-bool truthiness bugs in `constraint_checking.py` are gone — predicates are ibis expressions now. |
| `gmnspy.schema.read_schema(path)` | `corral.spec.load_package(path)` / `netstead.load_gmns_spec(version="0.97")` | Multi-version spec support; `DEFAULT_SPEC = "0.97"`. |
| `gmnspy.schema.read_config(config_file, data_dir, schema_dir)` | `Network.from_source(path)` (auto-discovery) | No more manual config wiring for the common case. |
| `gmnspy.schema.document_schemas_to_md(...)` | `corral.docgen.schemas_to_md(package)` / `corral.docgen.package_to_md(package)` | Same idea, generalized; takes a `corral.spec.DataPackage`, so it honors version selection. |
| `gmnspy.utils.logger` | `import logging; logging.getLogger("netstead")` | The `utils` grab-bag is gone. |
| `gmnspy.utils.list_to_md_table` | — | Gone; see below. |
| (no CLI) | `netstead validate <path>` / `netstead info <path>` / `netstead quality <path>` / `corral validate <path>` | Data commands accept `--json`; `validate` and `convert` also accept `--yes` to auto-approve gated ops. |
| (no editing API) | `with corral.editing.Session(net) as s: netstead.clean.simplify_geometry(net, s)` | Atomic rollback + audit log. |
| (no network-aware scope) | `netstead.scope.from_nodes(net, [...], path_between=True).apply()` | Network buffer, spatial buffer, connected component, zone filter — all chainable. |

## What's gone (no replacement)

These v0.3 surfaces were removed because they were either unsound or
subsumed by the new engine:

- **`gmnspy.validation.constraint_checking`** — the per-row validators
  there had latent Series-vs-bool truthiness bugs (`if some_series:`)
  that silently passed. Replaced by ibis-first predicates evaluated on
  pyarrow samples; the failure mode is structurally impossible.
- **`gmnspy.utils`** — the grab-bag is gone. GMNS-specific name handling
  lives in `netstead.semantics`; logging is stdlib `logging`; the markdown
  table helper has no replacement (use `corral.docgen` for spec docs, or
  `pandas.DataFrame.to_markdown`).
- **Implicit `pandas` everywhere.** Tables are lazy ibis expressions by
  default. If you mutated a returned DataFrame in v0.3 expecting the
  change to stick on the network, you must now go through an editing
  `Session` (see below).
- **`read_gmns_network` returning a bare dict.** The `Network` object
  exposes the same tables as attributes (`net.nodes`, `net.links`, …)
  but those attributes return lazy `Table` wrappers, not DataFrames.

## What's new

- **Modern formats out of the box.** Parquet (incl. partitioned),
  DuckDB, zip-CSV, and HTTP(S) URLs with a credentials cascade. Try
  `corral.read("s3://bucket/network.parquet", credentials=...)`.
- **Multi-version GMNS spec.** v0.95 / v0.96 / v0.97 ship side-by-side;
  default is 0.97. Per-call override:
  `Network.from_source(path, spec_version="0.96")`.
- **Network-aware scoping.** BFS, Dijkstra network buffer, spatial
  buffer from any link / point / node, connected-component, zone
  filter — chainable. See `netstead.scope`.
- **Data-quality framework.** 7 GMNS rules out of the box; plugin
  pattern for custom rules. Surface: `netstead quality <path>`.
- **Editing with rollback.** `netstead.clean.simplify_geometry`,
  `merge_close_nodes`, `remove_orphans`, `recompute_lengths`. All run
  inside an atomic `corral.editing.Session` with an audit log.
- **CLI + AI surface.** `netstead --help`. Every data command takes
  `--json` for machine-readable output; `netstead mcp serve` runs the MCP
  server for Claude Desktop / Claude Code.
- **Reports.** `report.to_html(path)` / `report.to_json()` /
  `report.to_rich()` render the same `ValidationReport` for humans,
  CI, or dashboards.

## Worked example: load + validate + filter a network

**GMNSpy v0.3.5**

```python
import gmnspy
import pandas as pd

# Load — returns a dict[str, DataFrame], validates eagerly
network = gmnspy.read_gmns_network("path/to/gmns/dir")

nodes = network["node"]
links = network["link"]

# Re-validate one table by hand
gmnspy.validation.apply_schema_to_df(
    nodes,
    schema_file="gmnspy/spec/node.schema.json",
    originating_file="node.csv",
)

# Filter to a subnetwork — pandas only, no FK awareness
keep = nodes[nodes["zone_id"] == 42]["node_id"]
sub_links = links[links["from_node_id"].isin(keep) & links["to_node_id"].isin(keep)]
```

**Netstead v1.0**

```python
from netstead import Network
from netstead import scope

# Load — lazy, format-agnostic, no eager validation
net = Network.from_source("path/to/gmns/dir")  # or .parquet / .duckdb / URL

# Validate everything (schema + FK + structural + sync-state) in one call
report = net.validate()
if not report.is_clean:
    report.to_rich()           # pretty-print to terminal
    report.to_html("report.html")
    raise SystemExit(1)

# Network-aware subnetwork: zone filter with FK pushdown to every related
# table (for a component, use scope.connected_component(net, seed_node_id))
sub = scope.from_zone(net, [42]).apply()

# Materialize only when you need to
nodes_df = sub.nodes.to_pandas()
```

Equivalent from the shell:

```bash
netstead validate path/to/gmns/dir --json > report.json
netstead info     path/to/gmns/dir
netstead quality  path/to/gmns/dir --json
```

## Breaking changes checklist

Before you upgrade, scan your codebase for each of these:

- [ ] Requirement `gmnspy` replaced with `netstead`.
- [ ] All `from gmnspy import …` and `from gmnspy.* import …` imports
      refactored to `netstead` — submodule paths changed too.
- [ ] Calls to `read_gmns_csv` / `read_gmns_network` replaced with
      `Network.from_source(...)` (or `corral.read(...)` for a single
      table).
- [ ] Code that mutated returned DataFrames in place now uses
      `corral.editing.Session` (or explicitly materializes with
      `.to_pandas()` and treats the result as a snapshot).
- [ ] Validation call sites updated — they receive a
      `ValidationReport`, not bare lists or `None`. Check `report.is_clean`
      / iterate `report.issues`.
- [ ] Tests that imported `gmnspy.validation._check_*` helpers switch
      to `Network.validate()` (or `corral.Package.validate()` for
      non-GMNS packages).
- [ ] `gmnspy.utils` imports rerouted: logger → stdlib `logging`,
      markdown helpers → `corral.docgen` (spec docs) or removed.
- [ ] Hard-coded references to `gmnspy/spec/*.schema.json` paths
      replaced with `netstead.load_gmns_spec(version=...)` or
      `netstead.get_spec_path(version=...)`.
